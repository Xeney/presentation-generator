# Задача

Собери презентацию {deck_size} слайдов по назначению «{purpose}».

## Бриф
```
{brief}
```

## Исходные материалы (контент-пакет)
```
{source}
```
Используй их как единственный источник фактов и цифр. Если материала нет —
работай только по брифу, без выдуманных цифр.

## Контекст шаблона (для твоего понимания объёма контента)
```
{profile}
```

## Доступные изображения из контент-пакета
{corpus_images}

Если изображение уместно на слайде, добавь блок с kind равным image и полем
image_ref, равным ключу из списка выше. Не выдумывай ключи: только из списка.

## Требуемая JSON-схема ответа
```json
{schema}
```

## Жёсткие ограничения (проверяются автоматически, за нарушение ответ отклоняется)
- первый слайд обязан иметь slide_type = "title";
- всего слайдов 10-15, не больше 15;
- содержание слайда — только в blocks: слайд типа "content" без блоков считается пустым;
- поле subheading — короткий подзаголовок (до 160 символов) для титула и раздела,
  а не текст слайда;
- в блоке bullets не больше 6 пунктов, каждый пункт не длиннее 15 слов;
- kind = "factoids" требует поле factoids вида [{{"value": "40%", "label": "времени отчётов"}}],
  данные в items для этого типа не принимаются;
- kind = "table" требует поле table, kind = "chart" требует поле chart с series;
- допустимы только типы слайдов и блоков, перечисленные в схеме.

Ответь ТОЛЬКО валидным JSON по схеме.
