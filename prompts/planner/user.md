```
{brief}
```

## Исходные материалы (контент-пакет)
```
{source}
```
Используй их как единственный источник фактов и цифр. Если материала нет —
работай только по брифу, без выдуманных цифр.

## Контекст шаблона (для твоего понимания объёма контента)
```
{profile}
```

## Доступные изображения из контент-пакета
{corpus_images}

Если изображение уместно на слайде, добавь блок с kind равным image и полем
image_ref, равным ключу из списка выше. Не выдумывай ключи: только из списка.

## Требуемая JSON-схема ответа

