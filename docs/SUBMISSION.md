## 2. Запуск (одна команда, проверено на чистой машине)

```bash
git clone git@github.com:Xeney/presentation-generator.git
cd presentation-generator
docker compose up --build        # первая сборка 4–9 мин, модели ~12 ГБ
```

* UI — <http://localhost:3000> (загрузить `examples/synthetic_16x9.pptx`,
  при желании `examples/builtin_corpus.md`, «Сгенерировать 3 варианта»);
* API — <http://localhost:8000/docs>; health — <http://localhost:8000/api/health>;
* локальный `.env` не обязателен: без него работают открытые веса Ollama;
* на **CPU**-машине рекомендовано: `cp .env.example .env` и
  `VLM_AUDIT_ENABLED=false` — полный прогон 135 с (`docs/REPRODUCIBILITY.md`).

Пошаговый лог чистого запуска с командами, выводом и временем —
`docs/REPRODUCIBILITY.md`. Демо-сценарий на 7 минут и план Б — `docs/DEMO.md`.

## 4. Проверки, которые можно повторить за 5 минут

```bash
pytest -q                                   # 180 тестов
python tools/audit_matrix.py                # матрица 8 шаблонов × 3 варианта: 24/24 чисто
python tools/audit_demo.py                  # аудит и авто-фиксы «до/после» (без модели)
python tools/demo_rehearsal.py --budget 420 # живой прогон с хронометражем (нужен сервис)
python tools/audit_matrix.py --layouts      # роли макетов на любом своём шаблоне
```

## 5. Команда и роли

| Роль | Зона ответственности |
|---|---|
| Капитан / архитектура | границы слоёв, контракты (`Deck`, план виджетов), ADR, приёмка |
| Backend / шаблоны | парсер профиля, роли макетов, вёрстка, рендер, аудит, авто-фиксы |
| ML / промпты | планировщик и VLM-аудит, промпты с версиями, grounding, генерация иллюстраций |
| Frontend / UX | панель брифа, просмотр трёх вариантов, отчёт аудита, авто-фиксы |
| Демо / питч | сценарий 7:00, репетиции, план Б, питч-колода, видео |

Контакты: указать в чате команды при отправке (в репозитории контакты не
публикуются, чтобы не собирать спам).

## 6. Что осознанно не сделано

Четыре trade-off'а с обоснованием (подробно — `docs/PROJECT_OVERVIEW.md` §8):
локальные 7B-модели на CPU не влезают в бюджет 5 минут (честный офлайн-fallback,
VLM-аудит выключается настройкой); VLM-аудит — опциональная недетерминированная
стадия; генерация иллюстраций по умолчанию выключена; сборка на кириллическом
пути требует `DOCKER_BUILDKIT=0` (на латинском работает штатно).
