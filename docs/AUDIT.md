# Аудит: проверки и покрытие

Аудит — часть пайплайна, а не внешняя проверка. Он состоит из двух независимых
подсистем:

* **детерминированная** (`backend/app/audit/checks.py`) — работает по XML/геометрии
  PPTX-файла. На одном и том же файле всегда даёт один и тот же результат;
* **контекстуальная** (`backend/app/audit/vlm.py`) — оценивает PNG-рендер слайда
  моделью Qwen2.5-VL по вопросам смысла. Может давать разные ответы на повторных
  запусках — это свойство метода, зафиксированное в Приложении 1 ТЗ.

Каждая проблема — объект `Issue {code, severity, slide, message, bbox}`.
`bbox` нормализован (0..1) и используется UI для красных рамок на миниатюре.
`severity = error` означает «не соответствует правилам шаблона/гайдлайнам»,
`warning` — «требует внимания пользователя».

Статусы: **есть** — реализовано и покрыто тестом, **частично** — реализовано без
теста или с известным дефектом, **план** — запланировано (этап из плана работ).

## 1. Детерминированные проверки

### 1.1 Вёрстка

| Проверка | Код | Severity | Статус | Тест |
|---|---|---|---|---|
| Элемент вышел за границы слайда | `out_of_bounds` | error | есть | `test_audit_catches_out_of_bounds` |
| Два блока наложились друг на друга | `overlap` | warning | есть | `test_audit_positive_case` (негативный кейс) |
| Текст не поместился в свою рамку | `text_overflow` | warning | есть | — |
| Текст обрезан краем слайда | `out_of_bounds` | error | есть | `test_audit_catches_out_of_bounds` |
| Нет изображения для блока-иллюстрации (остался слот) | `image_missing` | warning | есть | `test_image_widget_falls_back_to_slot` |
| Блоки не выровнены по направляющим макета | `misaligned_to_grid` | warning | план (этап 3) | — |
| Контент заходит в поля у краёв | `content_in_margins` | warning | план (этап 3) | — |
| Картинка растянута, пропорции нарушены | `image_stretched` | error | план (этап 3) | — |

### 1.2 Соответствие шаблону

| Проверка | Код | Severity | Статус | Тест |
|---|---|---|---|---|
| Шрифт не из шаблона | `font_not_allowed` | error | есть | — |
| Гарнитур больше двух на колоду | `too_many_typefaces` | warning | план (этап 3) | — |
| Кегль не из типографической шкалы шаблона | `font_size_not_in_scale` | error | план (этап 3) | — |
| Цвет не из палитры шаблона | `color_not_allowed` | error | есть | — |
| Слайд собран не на макете из шаблона | `layout_not_from_template` | error | план (этап 3) | — |
| Логотип или колонтитул сдвинуты с места | `branding_shifted` | warning | план (этап 3) | — |
| Контраст текста к фону ниже 4.5:1 | `contrast_too_low` | error | есть | — |

### 1.3 Плотность

| Проверка | Код | Severity | Статус | Тест |
|---|---|---|---|---|
| Больше 6 буллетов на слайде | `too_many_bullets` | error | есть | — |
| Буллет длиннее 15 слов | `bullet_too_long` | error | есть | — |
| Таблица больше 7 строк или 5 колонок | `table_too_big` | error | есть | `test_audit_catches_table_too_big` |
| Больше 5 серий на диаграмме | `too_many_series` | error | есть | `test_audit_catches_too_many_series` |
| Слайд заполнен меньше чем на четверть | `slide_too_sparse` | warning | план (этап 3) | — |
| Слайд заполнен больше чем на три четверти | `slide_too_dense` | warning | план (этап 3) | — |

### 1.4 Целостность

| Проверка | Код | Severity | Статус | Тест |
|---|---|---|---|---|
| Файл не открывается | — (исключение при разборе) | error | есть | `test_render_rejects_garbage`, `test_audit_rejects_broken_file` |
| Текст-заглушка (lorem ipsum, XXX, TODO, «вставьте текст») | `placeholder_text` | warning | есть | `test_audit_catches_placeholder_text` |
| Пустой слайд или слайд с одним заголовком | `empty_slide` | warning | есть | — |
| Слайд оказался картинкой, а не редактируемыми объектами | `raster_slide` | error | есть | `test_audit_catches_raster_slide` |
| Диаграмма без подписей осей, единиц или легенды | `chart_unlabeled` | warning | план (этап 3) | — |
| Два слайда дублируют друг друга | `duplicate_slide` | warning | план (этап 5, эмбеддинги BGE-M3) | — |
| Повторяющийся заголовок | `duplicate_heading` | warning | есть | — |

Сводка по шаблонам и вариантам — `python tools/audit_matrix.py`: на 3 шаблонах VK и
3 синтетических фикстурах все три варианта вёрстки дают **0 ошибок и 0 замечаний**
(проверено на дату 2026-09-23).

## 2. Контекстуальные проверки (VLM)

11 вопросов Приложения 1 ТЗ, на вход — изображение слайда. Промпты:
`prompts/vlm/system.md`, `prompts/vlm/user.md`; версия промпта пишется в
результат задания.

| № | Вопрос ТЗ | Как проверяется | Статус |
|---|---|---|---|
| 1 | Заголовок содержит вывод, а не просто называет тему | VLM | есть |
| 2 | Содержимое слайда соответствует заголовку | VLM | есть |
| 3 | Слайд пересказывается одним предложением | VLM | есть |
| 4 | Все цифры и факты со слайда есть в исходных материалах | VLM + grounding по BGE-M3 | план (этап 5) |
| 5 | На слайде есть содержание, а не только заголовок | VLM | есть |
| 6 | Картинки и иконки относятся к теме слайда | VLM | есть |
| 7 | Нет служебного мусора: реплик спикера, кусков промпта | VLM | есть |
| 8 | Текст без опечаток | VLM | есть |
| 9 | Вся колода на одном языке | VLM с межслайдовым контекстом | план (этап 5) |
| 10 | Все строки таблицы и элементы легенды работают на мысль слайда | VLM | есть |
| 11 | Соседние слайды связаны между собой по логике | VLM с межслайдовым контекстом | план (этап 5) |

## 3. Авто-фиксы

Детерминированные исправления выбранных пользователем проблем (без LLM):

| Проблема | Фикс | Статус |
|---|---|---|
| `text_overflow`, `bullet_too_long` | уменьшить кегль на шаг типографической шкалы | план (этап 4) |
| `out_of_bounds`, `content_in_margins` | подвинуть блок в границы/поля макета | план (этап 4) |
| `slide_too_dense` | разбить слайд на два | план (этап 4) |
| `layout_not_from_template`, `misaligned_to_grid` | сменить макет на подходящий по роли | план (этап 4) |
| `chart_unlabeled`, `table_too_big` | заменить визуал (таблица ↔ диаграмма) | план (этап 4) |
| `placeholder_text` | удалить блок-заглушку | план (этап 4) |

## 4. Область покрытия

| Слой | Что покрыто тестами |
|---|---|
| Парсер шаблонов | 3 шаблона VK + синтетические фикстуры (этап 7) |
| Планировщик | офлайн-fallback, Pydantic-валидация, конфиг назначений, короткий бриф |
| Вёрстка | три варианта, все проходят аудит (этап 7) |
| Рендер | round-trip PPTX, отказ на мусоре, нативность объектов, image-виджет (этап 1) |
| Детерминированный аудит | позитивный кейс, ловля проблем, каждая проверка — негативный кейс (этап 3) |
| VLM-аудит | мок-клиент, отсутствие Ollama (этап 7) |
| Экспорт | HTML содержит контент, нет утечки секретов, PDF/PPTX открываются |
| Сквозной прогон | `scripts/e2e.sh` на фикстурах + незнакомом шаблоне (этап 7) |

## 5. Как воспроизвести

```bash
pytest -q                                  # модульные тесты backend
python tools/audit_check.py <deck.pptx>    # аудит готового файла из CLI
scripts/e2e.sh                             # сквозной прогон с замерами
```
